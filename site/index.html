Quiet Wells · Built with AI

How do we remember ideas that change us?

Some of the most meaningful ideas I heard each week disappeared into notebooks I rarely opened again.

I built Quiet Wells to capture sermon notes, connect ideas across time, and create space to reflect on them instead of simply storing them.

What it taught me Context beats perfect transcription.

Handwriting is messy. But AI can use surrounding context to recover meaning even when every individual word is not perfect.

Dad Mode · Built with AI

How do we make growth easier for busy dads?

Most dads do not need more information. They need less friction.

I built Dad Mode to do more of the work behind the scenes and give dads a simple interface for moving toward their goals without making life feel like another full-time job.

What it taught me Personality is a product feature.

The AI coach became exactly what I instructed it to become. When I made Atlas too harsh, users felt it immediately. Improving how it communicated mattered more than adding another feature.

BUILD 04 · THINGS ESCALATED

It started with Minecraft. That didn’t last long.

Minecraft became the excuse. The real project became learning how to build and operate software with AI as a genuine collaborator.

  1. Minecraft

    Host a private Java server for family and friends.

  2. Docker

    Make the services isolated, repeatable, and manageable.

  3. API

    Expose server status and persist useful world data.

  4. Custom plugin

    Save locations directly from inside the game with /mark.

  5. World Atlas

    Search, view, copy, rename, and manage saved locations.

  6. AI engineering system

    Add standards, verification rules, operational scripts, pull requests, documentation, and human review.

I stopped treating AI like a chatbot and started treating it like a teammate. That teammate needed context, standards, feedback, verification, and the occasional firm disagreement.
