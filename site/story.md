# Built in a Day

*A Wednesday afternoon experiment inspired by Obvious.*

---

# Act I — Applying Felt Boring

Hi Obvious.

I almost clicked **Easy Apply**.

Instead...

I opened a blank GitHub repository.

Not because I thought it would guarantee an interview.

Because your job description genuinely excited me.

Most job applications tell you what someone has done.

I wanted to show you how I think.

So I blocked off my Wednesday afternoon and started building.

If you're reading this, thank you for taking a few minutes to explore it.

↓

---

# Act II — Why This Role?

I've spent the last decade solving very different problems.

Some wore steel-toed boots.

Some sat behind enterprise infrastructure.

Some involved coaching dads.

Lately, they've all involved AI.

Each one taught me something different.

But they all had one thing in common.

I like building systems that help people.

Lately, AI has completely changed how I think about building those systems.

Not because it writes code.

Because it changes what's possible when humans and AI genuinely collaborate.

Reading your job description felt familiar.

Not because I've already done everything you're asking for.

Because these are the exact kinds of problems I've been voluntarily spending my evenings and weekends exploring.

That felt worth building something for.

↓

---

# Act III — A Pattern I Didn't Notice

When I stepped back, I realized something.

I keep building.

Not because anyone tells me to.

Because I get curious.

The projects keep changing.

The pattern doesn't.

Quiet Wells.

Dad Mode.

Ballards Platform.

This project.

Different ideas.

Same motivation.

Find something interesting.

Learn everything I can.

Build until it works.

Then keep improving it.

↓

---

# Act IV — The Project That Changed Everything

This project started because I wanted a private Minecraft server for my family.

That didn't last long.

Somewhere along the way it became:

• Docker services
• A Flask API
• A custom Paper plugin
• A World Atlas
• GitHub workflows
• Engineering standards for AI
• Operational scripts
• Documentation
• Secure remote access
• Product thinking

Minecraft slowly became the excuse.

The real project became learning how humans and AI could build software together.

That changed how I think about engineering.

↓

---

# Act V — What Changed

A week ago I thought AI was mostly about prompts.

I don't believe that anymore.

Today I think:

Good context matters more than clever prompts.

Documentation isn't overhead.
It's shared memory.

Verification matters more than confidence.

The first answer is almost never the best answer.

The workflow matters more than the model.

Those lessons didn't come from reading articles.

They came from building.

↓

---

# Act VI — Why I Think We'd Get Along

I'm not going to pretend that twelve years of VMware magically became twelve years of React.

It didn't.

I still have plenty to learn.

But I do know how to own ambiguous problems.

I know how to learn quickly.

I know how to document decisions.

I know how to collaborate.

I know how to ask better questions today than I asked yesterday.

Most importantly...

I genuinely enjoy this.

Apparently enough to spend a Wednesday afternoon building an application instead of submitting one.

↓

---

# Act VII — One Thought

While building this, I couldn't stop thinking about one product idea.

Not because I think I know your product better than you do.

Quite the opposite.

Because building this forced me to think like one of your users.

I'd love to share that idea with you.

Not because it's "the answer."

Because I think good product conversations start with curiosity.

↓

---

# Act VIII — Thank You

Whether this turns into an interview or not...

Thank you.

Your job description made me close LinkedIn...

...and open a blank repository.

That felt like a pretty good trade.

— Josh
